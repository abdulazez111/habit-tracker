# 🎯 Habit & Productivity Tracker

A clean, interactive, and comprehensive productivity dashboard built with **Python**, **Streamlit**, **Pandas**, and **Plotly**.

## ✨ Features
- **Habit Management**: Add, delete, and track daily habits with precise date and time.
- **Interactive Tables**: Edit habit statuses directly from the grid.
- **Performance Analytics**: Visual charts (Donut & Bar charts) tracking completion ratios and category distributions.
- **Weekly Schedule**: Organize and manage weekly tasks/appointments with completion tracking.
- **Data Persistence & Export**: Local CSV storage with backup export capabilities.

## 🛠️ Tech Stack
- **Python**
- **Streamlit** (UI & Web App Framework)
- **Pandas** (Data Manipulation)
- **Plotly Express** (Interactive Charts)

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/abdulazez111/habit-tracker.git](https://github.com/abdulazez111/habit-tracker.git)
    ```
2. Install dependencies:
     ```
   pip install streamlit pandas plotly
     ```
3. Run the application:
     ```
   streamlit run app.py
     ```
